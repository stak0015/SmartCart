# SmartCart 测评操作指南（中文）

> 用途：发给外部测评人，请其按本指南完整试用 SmartCart 并逐条记录结果。
> 适用版本：分支 `randy/us3.4`（含 Epic 1、Epic 2、Epic 3 全部已实现功能）。
> 预计用时：环境启动约 5–10 分钟；测评约 30–40 分钟。

---

## 一、测评人的角色

请按"真实用户"的视角使用本应用：目标是为马来西亚低收入家庭找到"购物篮总价 + 返程交通费"最实惠的购物地点。请**不要提前看代码**，只看界面操作；每一步按"预期"核对"实际"，不一致就记下来并截图。

---

## 二、环境启动清单（演示前必做）

按顺序执行，每一步确认输出后再做下一步。

### 1. 启动 Docker Desktop
打开 Docker Desktop，等托盘图标变为稳定状态。确认数据库容器：
```
docker ps --filter "name=smartcart-postgres"
```
应显示 Status 为 Up。若没有，执行 `docker start smartcart-postgres`。

### 2. 启动后端
```
cd backend
uvicorn main:app --reload --port 8000
```
看到 `Uvicorn running on http://0.0.0.0:8000` 即成功。

**健康检查**：浏览器打开 `http://localhost:8000/api/health`，应返回
`{"status":"ok","item_rows":757}`（数字为 757 左右）。

### 3. 启动前端
```
cd frontend
pnpm dev
```
打开 `http://localhost:3000`，应看到 SmartCart 首页（商品搜索界面）。

### 4. 地点搜索冒烟测试
在首页进入 Choose location，位置框输入 `Putrajaya`：
- 出现下拉建议 → 环境正常，继续第三节。
- 提示错误/无建议 → **停止测评**，把错误现象反馈给开发组（大概率是 Google API 密钥过期，需要开发组更换密钥并重启后端）。

## 三、演示数据准备（每轮测评都这样做）

1. 首页搜索 `ayam`，给 **AYAM BERSIH - STANDARD** 点 **+ Add to basket**，数量设为 2。
2. 再搜 `mutton`，把羊肉商品加进购物篮，数量 1。
   （这两件组合能同时测出"完整购物篮"和"不完整购物篮"两种门店。）
3. 点右上角购物篮图标进入购物篮页，确认两件商品都在。

## 四、测评脚本

> 每条格式：操作 → 预期。逐项打勾（✅/❌），❌ 必须截图 + 简述现象。

### Epic 1 — 购物篮搭建（US 1.1–1.6）

| # | 操作 | 预期 |
|---|------|------|
| E1.1 | 搜索框输入 `beras` | 出现结果列表，最多每页 25 条，底部显示 "Page X of Y" |
| E1.2 | 输入单个字符 `b` | 不发起搜索（输入至少 2 个字符才搜索） |
| E1.3 | 搜索一个不存在的词，如 `zzzqqq` | 显示"没有符合条件的商品"类提示 |
| E1.4 | 勾选 1–2 个分类筛选项 | 结果只含所选分类；再点一次取消筛选后结果恢复 |
| E1.5 | 点某商品卡片查看详情/包装规格 | 显示官方商品名、包装规格、分类 |
| E1.6 | 同一商品点两次 + Add to basket | 购物篮内数量增加，不产生重复行 |
| E1.7 | 购物篮页改数量、删除一件 | 数量正确变化；删除后该行消失 |
| E1.8 | 购物篮页快速连点加减按钮、手动输入 0 或 999 | 数量被限制在 1–99，出现相应错误提示 |

### Epic 2 — 可达门店推荐（US 2.1–2.4）

| # | 操作 | 预期 |
|---|------|------|
| E2.1 | Choose location → 输入 `Putrajaya` → 选第一条建议 | 出现 "Location selected"，显示所选地点 |
| E2.2 | 交通方式选 Car，限制选 Distance 10 km | 选项被记住并显示 |
| E2.3 | 点 Find reachable stores | 出现门店卡片（约 9 家），含距离/时间/小计信息 |
| E2.4 | 浏览卡片排序 | 完整购物篮排在前面；综合成本（小计 + 返程费）由低到高 |
| E2.5 | 切换 Complete / Incomplete 标签 | 不完整购物篮门店在独立标签下，标注缺哪些商品价格 |
| E2.6 | 键盘按 Tab 移到某张卡的 "Select store"，回车 | 进入该门店的概览页（证明键盘可达） |
| E2.7 | 概览页核对 | 标题 "Recommended store: 店名"；显示店名、地址、SARA 徽章、Basket + transport total、小计、返程费、距离、时间、交通方式、限制、覆盖率 |
| E2.8 | 点 Back to recommendations | 回到列表，列表原样保留、不重新加载 |
| E2.9 | 概览页底部说明区 | 写明路线为估算、排名依据；不出现 "cheapest / in stock" 类断言 |

### Epic 3 — 省钱替代（US 3.1–3.4）

| # | 操作 | 预期 |
|---|------|------|
| E3.1 | 购物篮页（未做任何替换时） | "Your savings" 卡显示 "No savings applied yet" + 引导查看 Smart Budget Alternatives |
| E3.2 | 进概览页，查看替代建议区 | 昂贵商品被标记；有替代的显示 "Swap & save"，无替代的说明原因 |
| E3.3 | 点 "Swap & save" | 购物篮该行被替换为新商品；按钮变为 Undo |
| E3.4 | 概览页摘要卡 | 显示 Original total、New total、"You save RM X.XX" |
| E3.5 | 核对算术 | 逐行省额之和 = You save 金额 = Original − New |
| E3.6 | 回购物篮页 | 摘要同步显示省了多少（不再是空态） |
| E3.7 | 点 Undo swap | 恢复原商品；两处摘要回到 "No savings applied yet" |

## 六、常见问题排查

| 现象 | 原因与处理 |
|------|-----------|
| 首页打开空白或一直转圈 | 后端没启动或数据库没启动，回到第二节第 1–2 步 |
| 位置搜索无建议/报错 | Google API 密钥过期或未配置，反馈开发组更换密钥并重启后端 |
| 推荐返回 0 家门店 | 出发地离有坐标的门店太远；改用 `Putrajaya`、`Seremban` 作出发地，交通方式选 Car、限制放宽到 10–20 km |
| 概览页路线距离/时间与直觉不符 | 路线是 Google 估算，且步行/摩托车模式有额外提示；属设计内行为 |
