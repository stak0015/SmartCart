AC 5.7.4 README — Export image & PDF generation
================================================

本次提交内容 / What this commit does
------------------------------------
接通清单导出的实际文件生成。Export checklist 对话框中的
Download as image 现在会下载一张 PNG：内容由 AC 5.7.2 的导出模型
渲染（标题、店名、日期、逐行名称/规格/数量/价格标注/购买状态/
手动添加标签），隐私边界不变，不含任何原始传感器数值。长店名与
长品名自动换行，不裁切。Download as PDF 调用浏览器打印，打印
样式确保输出只含导出清单——无导航、按钮或对话框，无空白页。
导出失败时对话框保持打开并显示可恢复的提示
"Export failed. Please try again."，清单数据不受影响。PNG 生成
库按需动态加载，不进入首屏包。新增文案支持英文与 Bahasa Melayu
双语。

Wires up the actual file generation behind checklist export. Download
as image now downloads a PNG rendered from the AC 5.7.2 export model
(title, store name, date, and per-row name / package size / quantity /
price annotation / purchase status / manually-added label); the
privacy boundary is unchanged and no raw sensor values are included.
Long store and item names wrap instead of being clipped. Download as
PDF invokes the browser print flow, and print styles ensure the output
contains only the export sheet — no navigation, buttons, or dialogs,
and no blank pages. If export fails, the dialog stays open with a
recoverable "Export failed. Please try again." message and the
checklist data is untouched. The PNG library is loaded on demand and
stays out of the initial bundle. New copy is bilingual (English and
Bahasa Melayu).
