# SmartCart 使用测评指南（普通用户版）

你好！这是一份不需要任何技术背景的测评任务。
你只需要像平时用手机买东西那样，试用一个帮我们家庭找"最划算的超市"的网站，并把过程录成一段 **5 分钟以内** 的视频。

## 网站地址

**https://smartcart-my.vercel.app/**

用电脑浏览器打开即可（建议 Chrome）。不需要注册、不需要登录。

## 这个网站是做什么的（30 秒了解）

假设你要去超市买一篮子东西：米、油、鸡肉……
这个网站帮你做两件事：

1. 让你选好要买的东西和数量；
2. 根据你的住址和出行方式（走路/开车/坐公交），算出去哪家超市买这些东西**总价最便宜**（商品钱 + 来回车费一起算）。

你的任务就是"假装真的要去采购"，把这个流程走一遍，边用边把心里话说出来。

---

## 使用方法：只要会做四步

### 第 1 步：选你要买的东西

1. 打开网站，你会看到一个搜索框（写着 Search）。
2. 输入你想买的商品关键词，比如输入 **ayam**（马来语"鸡肉"）。
3. 下面会出现商品卡片。每张卡片上有 **+ Add to basket** 按钮，点一下就把商品放进购物篮。
4. 建议挑 2–3 件放进购物篮（比如鸡肉、米、油）。屏幕右上角的购物篮图标会显示你放了几件。

💡 想换个关键词也可以，比如搜 **beras**（米）、**minyak**（油）、**telur**（蛋）。

### 第 2 步：检查你的购物篮

1. 点右上角的**购物篮图标**。
2. 这里能看到你选的所有商品和数量，可以用 **＋ / −** 改数量，用垃圾桶图标删掉不要的。
3. 看完后点底部的 **Choose location** 按钮，进入下一步。

### 第 3 步：选你的位置和出行方式

1. 在位置输入框里输入 **Putrajaya**（布城），从下拉建议里点第一个。
   ⚠️ 请务必用 **Putrajaya** 这个地点——测试用的商店数据集中在这里，换成别的地方可能搜不到商店。
2. 选出行方式：点 **Car**（开车）那个图标。
3. 选距离限制：点 **10 km**。
4. 点底部的 **Find reachable stores**。

### 第 4 步：看哪家商店最便宜

1. 页面会列出一排商店卡片，**排最前面的就是推荐你的商店**（买齐你所有东西、总价最便宜）。
2. 每张卡片上能看到：商店名字、商品总价（Basket subtotal）、来回车费（Return travel）、总共要花多少钱（Combined total）、路程距离和时间。
3. 点任意一张卡片上的 **Select store** 按钮，进入这家店的详情页。
4. 详情页里有一张 **Item prices** 表：你买的每一样东西在这家店卖多少钱、单价 × 数量 = 小计，一目了然。

## 录视频建议（5 分钟以内）

按下面的顺序边操作边说就行，不用背台词，说错了也没关系：

| 顺序 | 你做什么 | 你可以说 |
|---|---|---|
| 1 | 打开网站 | "我想买点鸡肉和米，先搜一下" |
| 2 | 搜索、加购 2–3 件商品 | "这个看起来不错，加进购物篮" |
| 3 | 打开购物篮看一眼 | "我买了三样东西，数量对不对" |
| 4 | 输入 Putrajaya、选 Car、选 10 km | "我住在 Putrajaya，开车去，最多开 10 公里" |
| 5 | 看商店列表 | "这家最便宜，因为商品钱加车费最低" |
| 6 | 点 Select store 看详情页 | "这里能看到每样东西多少钱" |
| 7 | 结束 | 说一句整体感受 |

**请边做边把想法说出来**（哪里好找、哪里看不懂、哪里卡住了），这正是我们要的信息。

## 注意事项

- 整个过程不需要付钱，也不涉及真实购物，放心点。
- 如果某一步等了很久或者页面报错，不用紧张，照实说出来、截图就好。
- 不需要刷新页面（刷新后购物篮会清空，要重新选）。
- 录完视频后，再简单回答 3 个问题（文字即可）：
  1. 哪一步最容易上手？
  2. 哪一步最让你困惑或卡住？
  3. 如果满分 5 分，你给这个网站打几分？为什么？

## 遇到问题找谁

任何打不开、报错、看不懂的界面，直接截图发给给你这份指南的人就行。
