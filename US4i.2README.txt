US 4i.2 README - Pre-festival price-rise banners
US 4i.2 交付说明 - 节前涨价提醒横幅
================================================================

1. What this commit does / 本次提交内容
----------------------------------------------------------------
中文：
- 新增节前涨价提醒 API：
  GET /api/festivals/alerts?state={state}&on={YYYY-MM-DD}
- 提醒触发条件：节日价格显著波动、关键窗口可用，且当前日期位于
  rise_start 至 rise_end 之间。
- 已设置州属时，只返回全国性节日与该州适用的州级节日；未设置州属时，
  只返回全国性节日提醒。
- 同一 item_code 跨州去重，并按上涨商品计算受影响商品数量。
- 在 Shop 与 Basket 页面显示一条汇总横幅，包含节日名称、预计涨价窗口、
  受影响商品数量和可展开商品清单。
- 横幅提供州属选择、Dismiss 和 View evidence。
- 同一窗口内关闭后，不再重复显示该提醒。
- View evidence 跳转到 US4i.1 证据页，并选中对应节日和州属。
- 提醒规则版本为 4i.2.1-v1，复用现有 price / window 数据集版本。
- 本提交不修改 PostgreSQL schema，不实现 US4i.3–4i.6。

English:
- Adds the pre-festival alert endpoint:
  GET /api/festivals/alerts?state={state}&on={YYYY-MM-DD}
- An alert is active when the festival is significant, its key window is
  ready, and the current date falls between rise_start and rise_end.
- When a state is set, only national festivals and state-level festivals
  applicable to that state are returned. Without a state, only national
  festivals are returned.
- Deduplicates each item_code across states and counts the affected items.
- Shows one summary banner on the Shop and Basket pages with the festival name,
  expected price-rise window, affected item count, and an expandable item list.
- The banner provides state selection, Dismiss, and View evidence.
- Dismissing hides the alert for the same session and window.
- View evidence opens the US4i.1 evidence page with the corresponding festival
  and state selected.
- The alert rule version is 4i.2.1-v1 and reuses the existing price/window
  dataset versions.
- This commit does not change the PostgreSQL schema and does not implement
  US 4i.3–4i.6.
