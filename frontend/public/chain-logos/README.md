# PriceCatcher chain logos

The image files are stored alongside [`manifest.json`](./manifest.json), which maps the 30 identified retailer names to local asset paths and records each source URL.

25 chains have a local logo asset. Five remain without a clean, verifiable standalone logo: **Pantai Timur, Salamku, Pasaraya LYC, Target, and Econjaya**. Pantai Timur is kept distinct from Pantai Timor, and Target refers to the Batu Pahat retailer.

The ManaMurah directory was used to confirm the chain list. The logo files were gathered from retailer, partner, mall, employer, and logo-host pages; no ManaMurah images were downloaded. Brand marks remain the property of their owners.
